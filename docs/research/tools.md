# Tools

The repository's tools and the build switches. Status tags as in [conventions.md](conventions.md).

| Tool | Purpose |
| --- | --- |
| `build.py` | Whole pipeline. `HX_NAM_SLOTS` (3, 2, 1, 0) sets NAM's slots; unset, the most that leave Block 3 room for the DSP features on (`HX_GR=1`: two). Runs `tools/patch_comp.py` last. |
| `tools/block3.py` | The Block 3 room each NAM slot count leaves, each DSP feature's cost and place in it. |
| `tools/l6ia.py`, `tools/l6ia_verify.py`, `tools/hxf.py` | Container parse/rebuild/verify/pack. |
| `tools/patch_amp.py` | Add models, IR titles, NAM's Model as a whole number (`model-int`), SHARC kernel, `--wrap-prim`. |
| `tools/patch_menu.py` | The feature categories of Global Settings and the engine that builds in the features of `tools/features/`. |
| `tools/features/` | One module a feature: settings, flag, inputs, hooks. |
| `tools/image_store.py` | Reads the image store: Entry 7's image and font records, Entry 8's items. |
| `tools/setting_ids.py` | The Global Settings IDs HXtra uses, one line each; `free` lists candidates. |
| `tools/usb_commands.py` | The HX Edit editor commands HXtra adds, one line per number, and the numbers stock 3.80 leaves free; a feature's M4 code gets its number as `CMD` from `usb.inc`. |
| `tools/patch_divider.py` | Home divider 2 px green. |
| `tools/patch_comp.py` | GR knobs on compressor models, and `src/sharc/frame_probe.asm` in Block 3 above NAM's two slots, wrapping the cores `0x271a`, `0x2719` and `0x2710` (`HX_GR=1` builds; after add-model and add-fx-model). |
| `tools/patch_splash.py` | Boot pictures: a 320x181 or full-screen 320x240 PNG as is, any other picture converted with macOS `sips` (fill or fit), packed for the image store; `export` saves the picture an image has now. The feature that builds them in, with the text and the renderer hook, is `tools/features/splash.py` (`build.py --splash`, `--splash-fit`, `--splash-text`; `hxsplash <picture> ["text"]` in the author's shell builds and RAM-runs it). |
| `tools/splash_emoji.py` | Emoji for the boot line: text split into emoji, an emoji's picture as a glyph of `hx21_regularFont`; used by `tools/features/splash.py`. |
| `tools/splash_topo.py` | A 320x240 boot picture: neon contour lines of a seeded random terrain. |
| `tools/emoji_png.swift` | Renders one emoji (Apple Color Emoji, macOS) to a PNG for `tools/splash_emoji.py`. |
| `tools/m4asm.py` | Assemble a Thumb-2 `.s` with clang (`HX_CLANG`, Apple's Command Line Tools or `PATH`): its `.text` and symbols; refuses relocations. |
| `tools/sharc/sasm.py`, `ssim.py` | SHARC assembler and simulator. |
| `tools/sharc/pmap.py` | A model's knobs traced through its parameter map (curves, nested maps) to the primitives and pids they set, with its signal chain ([sharc/model-blobs.md](sharc/model-blobs.md)); runs on every stock effect model (830, all categories); `--category distortion,eq --json F` for many; `--sweep` evaluates the map ops and gives each writer's value over each knob's range. |
| `tools/sharc/biquad102.py` | The `0x102` biquad's coefficients for a type, frequency, gain and Q, by interpreting the stock coefficient code (`0x60a603`, disassembled from the stock file at run time, type cases through the jump table at DM `0xc72dc`) ([sharc/cores/filters.md](sharc/cores/filters.md)). |
| `tools/sharc/visa_dis.py` | SHARC disassembler for Entry 2: 48-bit ISA in PM (`--pm`) and VISA at short-word addresses ([sharc/visa.md](sharc/visa.md)). |
| `tools/hxf_ram.py`, `tools/ramboot/` | Run an image from RAM over USB. |
| `src/sharc/frame_probe.asm` | DSP-side wrapper and frame-tail writer of the GR meter, beside the NAM kernel. |
| `src/m4/gr_meter.s` | M4 receive hook, Home constructor and paint hooks, and the Edit view's two paints: the ten-light GR meter and its Position, Direction and Thickness settings. |
| `tools/gr_meter.hex` | Generated by `python3 tools/m4asm.py src/m4/gr_meter.s \| tail -1 > tools/gr_meter.hex`. |
| `tools/features/dsp_meter.py`, `src/m4/dsp_meter.s` | The DSP meter: each block's DSP cost and the blocks' total in the Edit view (`HX_DSP_METER=1`). |
| `tests/m4emu.py` | Runs an M4 module in unicorn (Cortex-M4 Thumb) against stubbed firmware functions, for tests. |
| `tools/features/bpm.py`, `src/m4/bpm.s` | The BPM on the Home screen and its beat dot (`HX_BPM=1`); `tests/test_bpm.py` runs its handlers in unicorn. |
| `tools/patch_click.py`, `src/sharc/click.asm` | The Metronome block (`HX_CLICK=1`): a model with a tempo-synced Time and its DSP kernel; `tests/test_click.py` runs the kernel in ssim. |
| `tools/patch_gate.py`, `src/sharc/fx_gate.asm`, `tools/features/fx_gate.py` | The FX Loop gate (`HX_FX_GATE=1`, opt-in on the web page): Gate, Threshold and Decay on the FX Loop and Return blocks, a wrapper around their return reader `0x2618` in Block 3 under the Metronome; runs after `patch_click.py`, before `patch_comp.py`; `tests/test_gate.py` runs the DSP code in ssim. |
| `tools/patch_sidechain.py`, `src/sharc/gate_sc.asm`, `tools/features/gate_sidechain.py` | Noise Gate Input Sidechain (`HX_GATE_SC=1`, a DSP feature on the web page): the Noise Gate's Input Sidechain knob, wrappers around the gate core `0x2720`, the Input block's jack reader `0x2a94` and meter `0x2390` keying it by the input; `tests/test_gate_sc.py` runs the wrapper in ssim. |
| `tools/features/screen_mirror.py`, `src/m4/screen_mirror.s` | The screen mirror (`HX_SCREEN_MIRROR=1`, not on the web page): HX Edit's editor service answers command 0x52 with the frame on the LCD. |
| `tools/hx_mirror.py`, `tools/mac/mirror_mac.swift` | The HX Stomp's screen on a Mac from a screen mirror build: a PNG (`shot`), a live window (`view`), an H.264 `.mov` with the controls used (`view --record`), the event codes of each control (`events`, `learn`), and `Session` for a script that drives the unit while it records. |
| `tools/mac/stomp_render.swift`, `tools/mac/skins/` | A recording set into a photo of the HX Stomp (photos in `build/art/`, out of git), its controls moving as they were used, as an MP4 small enough to attach on GitHub, or with `--gif` a looping 480 × 360 GIF of part of it (`hx_mirror.py gif`). |
| `tools/features/usb_input.py`, `src/m4/usb_input.s` | USB input (`HX_USB_INPUT=1`, not on the web page): HX Edit's editor service takes command 0x51, UI events the unit queues as its own controls do. |
| `tools/hx_input.py` | Presses, holds and turns the HX Stomp's footswitches, knobs and buttons from a USB input build; `Input(ctl)` for scripts. |
| `tools/hx_freqresp.py`, `tools/mac/noise_mac.swift`, `tools/freqresp/` | The magnitude response of stock blocks over USB: per case (a JSON file, examples in `tools/freqresp/`) one block in slot 0 of path A, fixed-seed noise into USB 5/6, USB 1 recorded (`tools/mac/record_mac.swift`), H1 by cross-correlation and Welch on 1/12-octave bands, divided by a reference case; -3/-6 dB points, flank slopes, boost or cut and half-gain points, optional expected curves (`--expect`); `--reanalyse` needs no unit. |
| `tools/hx_freqresp_expect.py` | The expected response of each case of a `tools/hx_freqresp.py` case file, for `--expect`: for blocks made only of `0x102` and `0x80` in series (the EQs), chain and knob values from `tools/sharc/pmap.py`, coefficients from `tools/sharc/biquad102.py`. `tests/test_hx_freqresp_expect.py` checks it against the unit's EQ measurement (`tests/data/freqresp_eq_unit.csv`). |
| `tools/hx_devtest.py`, `tools/mac/ocr_mac.swift` | A test of each feature on the running unit, pressing its controls (`hx_input.py`) and reading its screen (`hx_mirror.py`, text by macOS Vision); never boots it. `QA.md` has how to run it. |

Build commands:

```sh
# normal build
python3 build.py HX_Stomp_v3.80.0_0x103966115.hxf
# gain-reduction meter (NAM takes two slots, the most that leave it room)
HX_GR=1 python3 build.py HX_Stomp_v3.80.0_0x103966115.hxf
# per-block DSP usage meter
HX_DSP_METER=1 python3 build.py HX_Stomp_v3.80.0_0x103966115.hxf
# BPM on the Home screen
HX_BPM=1 python3 build.py HX_Stomp_v3.80.0_0x103966115.hxf
```
